# corpus/

Place your own legally-obtained copy of the PDF here, e.g.:

```
corpus/rich_dad_poor_dad.pdf
```

The filename should match `BOOK_PDF_PATH` in your `.env`.

**Do not commit the PDF.** It's excluded via `.gitignore` (`corpus/*.pdf`) —
the book is copyrighted, and this repo is public. Only this README is
tracked so the folder exists after cloning.
